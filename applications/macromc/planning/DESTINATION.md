# 最大愿景
* 这是一个长期愿景，大概率最终无法完成，或者要花费数年缓慢完成一部分。
* 但是它仍然对我们目前的系统设计、参数取舍、技术选择有相当指导意义。
### 平台目标
面向近未来的发烧级设备，或者说现在的顶级设备（64G-128G DDR5内存，24G显卡且光追性能极佳）
### 核心需求
* 每玩家64km视距【WIP，目前目标】

* 4-5玩家联机（每玩家加载32x32区块参与Gameplay Tick）

* 多个、大型（2000 sub chunk级）WorldShell物理交互：刚体碰撞、面摩擦、断裂，实时变更。
  * Shell总数量可能超过1000，但总Subchunk可能只有32k以下（大量都是一个subchunk可以表示的小shell）。

* 全局自然迭代系统——不止在已加载ticking区块发生，在未加载区块也必须进行，这更多需要渲染层适配。
  * 比如，短期：下雪会积雪，太阳会融雪。长期：建筑会风化、荒地会长草、季节会变化等。
  * 可以采用懒运算的方式——远处区块卸载后再次加载时，lazily计算天气在这段时间产生的影响？

* 自然风系统，影响到云表现和VC区块表现，纯渲染，这部少量涉及Gameplay（对Gameplay只读），远期目标

* 百万级粒子系统，不过这是个相对独立的渲染扩展，也不太设计Gameplay，远期目标

* 温度计算系统，这个影响Gameplay，而且要跨worldshell，只在已加载区块上计算即可，远期目标
